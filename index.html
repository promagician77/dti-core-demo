Why some items can't be recolored

A MeshPart's color only shows through transparent parts of its texture. Clothing has to be made that way. Most marketplace UGC isn't, so the wheel can't touch it.

Decide this first: custom clothing built for recoloring, marketplace UGC, or a mix. It shapes the whole asset pipeline.

      Session lock — why unlocks never duplicate
      

      store:UpdateAsync(key, function(old)
  local lock = old.lock
  if lock and lock.job ~= game.JobId
     and os.time() - lock.time < LOCK_TTL then
    return nil -- other server holds it: don't load stale data
  end
  old.lock = { job = game.JobId, time = os.time() }
  return old
end)
